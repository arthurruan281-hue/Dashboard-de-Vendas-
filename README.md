# Relatório - Dashboard de Vendas (Excel)

## 1. Descrição do desafio
O desafio consiste em criar um dashboard de vendas no Excel, organizando e transformando dados brutos em visualizações e indicadores que permitam analisar o desempenho de vendas e apoiar a tomada de decisão.

## 2. Base de dados
- Arquivo: `dados/base.xlsx`
- Observação: a base foi utilizada como fonte para criação de tabelas dinâmicas e gráficos.

## 3. Processo de construção (passo a passo)
1. Importação/abertura da base e organização em formato de tabela (Ctrl + T)
2. Criação de tabelas dinâmicas para consolidação dos dados
3. Criação de gráficos a partir das tabelas dinâmicas
4. Montagem do dashboard em uma aba exclusiva, com layout limpo e visual
5. Inclusão de filtros/segmentações para tornar a análise interativa
6. Testes de atualização (Dados > Atualizar Tudo) e validação do resultado

## 4. Indicadores e análises presentes
- Faturamento total
- Quantidade total vendida
- Análises por período (ex: mês)
- Ranking/Top produtos (quando aplicável)
- Distribuição por categoria/região (quando disponível na base)

## 5. Como executar/reproduzir
1. Baixe o repositório
2. Abra o arquivo `dashboard/dashboard_vendas.xlsx`
3. Se necessário, clique em **Dados > Atualizar Tudo**
4. Utilize os filtros no dashboard para alterar a visão dos dados
